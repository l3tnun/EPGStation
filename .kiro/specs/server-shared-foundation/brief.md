# 共有基盤ユーティリティ機能

## この機能が提供するもの

複数のサーバー機能から共通して利用される、汎用処理の直列化、日時表示、文字列正規化、ファイル操作という基盤的な振る舞
いを、各利用機能から独立して説明・検証できるようにする機能である。この機能自体は EPGStation の予約、録
画、配信などの製品としての振る舞いを追加・変更しない。

対象は次の 5 つの基盤的な振る舞いである。

1. **処理の直列化**: 複数の非同期処理を追加された順に開始し、前の処理の失敗を呼び出し元へ正しく伝え、後続の処理を失わ
   ないようにする。
2. **日時表示**: 日時を決められた書式文字列に変換する表示、および日本時間への変換を提供する。
3. **文字列正規化**: データベースに格納できない文字の除去、全角・半角の相互変換、ファイル名やディレクトリ名に使えない
   記号の置換、番組表で使われる囲み文字の相互変換を提供する。
4. **ファイル操作**: ファイルの読み書き、削除、名前変更、移動、一覧取得、および管理対象ディレクトリ配下だけを安全に削
   除対象と判定する処理を提供する。
5. **単純な時間待機**: 指定時間が経過するまで完了しない待機処理を提供する。

## 対応実行環境

-   Node.js 24 系を最低対応版とする
-   Node.js 24 系で外部から観測可能な振る舞いを確認する

## 処理の流れ

利用側の機能は、この機能が提供する処理を呼び出し、戻り値または例外を受け取る。この機能は呼び出し元の状態や設定を保持
せず、渡された入力に対してだけ振る舞う。

## 他の機能との関係

### 利用する機能

-   なし。

### この機能を利用する機能

-   3 つ以上のサーバー機能から利用される、固有の lifecycle または contract を持つ基盤処理として、複数のサーバー機能が
    利用する。個々の利用先の業務判断はこの機能に記述せず、各利用機能の仕様が所有する。

## この機能に含めないもの

-   個々の利用機能が固有に必要とする業務判断や状態
-   単一の機能だけが使う変換・補助処理（その機能自身の仕様が所有する）
-   共有テスト基盤（サーバー起動・稼働管理機能が所有する test root、runner、coverage の実行方法）

## 未確認事項

-   現時点では振る舞いを確認するだけであり、将来の変更予定はない。
