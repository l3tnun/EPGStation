# 録画保存先の容量管理機能

## この機能が提供するもの

録画保存先の総容量、使用量、空き容量を提供し、設定された空き容量以下になった保存先で通知用の外部コマンドや録画済み番組の
自動削除を開始する機能である。

容量表示は自動削除の有無にかかわらず利用できる。容量監視は設定された録画保存先ごとに行い、一回の監視処理が続いている間は
次の監視処理を重ねない。

## 主な機能

### 保存先の容量表示

-   設定されているすべての録画保存先を対象にする
-   保存先ごとに設定名、総容量、使用量、空き容量を提供する
-   容量表示の数値はバイト単位で提供する
-   自動削除を設定していない保存先も表示対象にする
-   同じ物理ディスク領域を指す保存先が複数ある場合も、設定された保存先ごとに表示する

### 空き容量の定期監視

-   空き容量の下限が設定された保存先だけを監視する
-   空き容量の下限は MB 単位、監視間隔は秒単位で扱う
-   設定された監視間隔が経過するたびに空き容量を確認する
-   最初の容量確認は監視開始から一回の監視間隔が経過した後に行う
-   一回の監視処理が終わる前に次の間隔を迎えた場合は、監視処理を重ねて実行しない
-   監視対象がない場合は定期監視を開始しない

### 容量不足時の通知

-   空き容量が設定値以下の場合、設定されていれば通知用の外部コマンドを起動する
-   通知用コマンドの完了を待たず、自動削除の設定に従って監視処理を続ける
-   起動した通知用コマンドには設定された有限の実行時間を適用し、超過時は停止を試みる
-   コマンド文字列を実行対象と引数に分け、親プロセスの環境変数を引き継いで起動する
-   コマンドの解析または起動要求に直ちに失敗した場合はログへ記録する

### 録画済み番組の自動削除

-   自動削除が設定されている場合、保護されていない録画済み番組を一件選ぶ
-   選んだ録画済み番組の削除を録画済み番組管理へ依頼する
-   一件削除するごとに監視対象の空き容量を取得し直す
-   最初の容量不足判定では、取得したバイト値をMBへ換算して設定値と比較する
-   削除後に再取得したバイト値も、MBへ換算して設定値と比較する
-   再取得した空き容量（バイト値）が前回より増えない場合、または同じ録画済み番組が再び候補になった場合は、その保存先の自動
    削除を終了する

### 監視の停止

-   停止要求を受けた場合は定期監視タイマーを解除する
-   停止要求はすでに開始している容量確認や削除の完了を待たない
-   通知用コマンドに設定した実行時間の監視は、定期監視タイマーの停止と分けて扱う

## 容量監視の流れ

1. 空き容量の下限が設定された録画保存先を監視対象にする。
2. 監視間隔が経過したら、設定順に各保存先の空き容量を取得する。
3. 空き容量が設定値を上回っている場合は、その保存先の処理を終える。
4. 空き容量が設定値以下の場合は、設定されていれば通知用コマンドを起動する。
5. 自動削除が設定されていれば、保護されていない録画済み番組の削除を依頼する。
6. 空き容量を取得し直す。バイト値が増えていなければ終了し、増えていればMBへ換算して設定値と比較する。設定値以下なら100ミリ秒待って次の候補へ進む。

## 異常時の動作

-   ある保存先の容量を取得できない場合は、その保存先の処理を中止して他の保存先を続ける
-   通知用コマンドの解析または起動要求に直ちに失敗した場合も、自動削除の設定に従って処理を続ける
-   通知用コマンドが実行時間を超えた場合は停止を試み、結果をログへ記録する
-   削除候補を取得できない場合、候補がない場合、削除に失敗した場合、削除後の容量を取得できない場合は、その保存先の自動削
    除を中止する
-   削除後に空き容量が増えない場合、または同じ録画済み番組が再び候補になった場合は、その保存先の自動削除を終える
-   監視停止後も、すでに開始している容量確認または削除が続く場合がある

## 他の機能との関係

### 利用する機能

-   サーバー設定管理機能（`server-configuration`）: 録画保存先、空き容量の下限、監視間隔、通知用コマンド、および自動削除
    条件を提供する。
-   運用ログ記録機能（`server-operational-logging`）: 容量確認、通知用コマンド、および自動削除の結果を記録する。
-   データベース保存・検索機能（`server-persistence`）: 自動削除候補となる録画済み番組を検索する。
-   録画済み番組管理機能（`server-recorded-content`）: 選ばれた録画済み番組と関連情報の削除を受け付ける。

### この機能を利用する機能

-   サーバー起動・稼働管理機能（`server-application-runtime`）: 起動時に録画保存先の容量監視を開始する。
-   Web・API・リアルタイム通知提供機能（`server-service-interface`）: 保存先ごとの容量情報を取得して外部へ提供する。

## この機能に含めないもの

-   録画先を選択し録画ファイルを書き込むこと
-   録画済み番組と関連ファイルを削除する具体的な手順
-   録画、エンコード、配信を停止すること
-   サムネイル、配信用一時ファイル、変換途中ファイルの保存期限を管理すること
-   保存容量を増やすことや保存先を別の機器へ移すこと
