# 録画済み番組管理機能

## この機能が提供するもの

録画した番組と、その番組に属する録画ファイル、ドロップログ、タグ、保護状態、録画履歴を管理する機能である。

利用者は録画済み番組を検索・参照し、手動作成、ファイル追加、タグ付け、保護、削除を行える。録画実行、ファイルアップロー
ド、エンコードから受け取った録画ファイルを登録し、関連情報と実ファイルの整理も行う。

## 主な機能

### 録画済み番組の管理と参照

-   録画済み番組へ0件以上の録画ファイルを関連付ける
-   ドロップログ、サムネイル、タグ、自動予約ルールとの関連を保持する
-   録画中、保護中、番組情報、放送局、開始・終了時刻を保持する
-   キーワード、放送局、ジャンル、自動予約ルール、録画ファイルの有無などで一覧を絞り込む
-   一覧、総件数、詳細、検索に利用する放送局とジャンルを提供する
-   待機中または実行中のエンコードがある場合は、録画済み番組の参照情報へ反映する

### 録画結果とファイルの登録

-   録画開始後に録画済み番組、録画ファイル、必要なドロップログを登録する
-   録画終了後に録画ファイルの最終的な大きさを更新する
-   一時録画先を利用したファイルを通常の録画先へ移した場合は登録先を更新する
-   録画済み番組だけを手動で作成し、後から録画ファイルを追加できる
-   エンコード結果の録画ファイルを既存の録画済み番組へ追加できる

### アップロードされたファイルの登録

-   受信済みの一時ファイルを既存の録画済み番組へ追加する
-   指定された録画保存先とサブディレクトリへファイルを移動する
-   同名ファイルがある場合は番号を付けた別名を選ぶ
-   表示名、種類、大きさ、所属する録画済み番組を登録する
-   対象番組または指定された録画保存先を確認できない場合は一時ファイルの削除を試みる
-   ファイル移動に失敗した場合は一時ファイルを、移動後の登録に失敗した場合は移動済みファイルの削除を試みる

### タグ、保護状態、自動予約ルールとの関係

-   タグの一覧、検索、追加、変更、削除を行う
-   録画済み番組とタグを関連付け、または関連を解除する
-   録画済み番組の保護状態を変更する
-   保護中の録画済み番組と録画ファイルの削除を拒否する
-   削除された自動予約ルールの識別番号を録画済み番組から取り除く

### 録画履歴

-   番組指定の自動予約が番組リレーではなく正常終了して予約削除を必要とする場合に録画履歴を追加する
-   自動予約ルールの重複回避に使う期間内の録画履歴を提供する
-   設定された保存期間を過ぎた録画履歴を削除する

### 動画情報の確認

-   録画ファイルから再生時間、ファイルサイズ、ビットレートを確認する
-   動画情報の確認に使う外部処理には、その処理に適した有限の実行時間を設定する
-   対象ファイルを確認できない場合や外部処理が失敗した場合は動画情報を返さない

### 録画済み番組とファイルの削除

-   利用者削除に必要なエンコード取消と録画停止の順序は機能間連携機能へ委ね、前提処理後の削除依頼を処理する
-   対象の存在、保護状態、および録画状態を確認し、この機能が所有する削除条件を適用する
-   録画ファイル、サムネイル、ドロップログと各登録情報を削除する
-   録画中ではない番組では個別録画ファイルを削除し、最後の録画ファイルを削除した場合は録画済み番組も削除する
-   録画中の番組で個別録画ファイル削除を要求した場合は、録画済み番組全体を削除する
-   削除結果を画面更新などの関係機能へ通知する

### 登録情報と実ファイルの整理

-   登録情報はあるが実ファイルがない録画ファイルとドロップログを整理する
-   録画保存先にあるが登録情報を持たないファイルを削除する
-   管理対象を含まない空ディレクトリを削除する
-   個別の整理に失敗しても、処理できる他の対象を続ける

## 主な利用の流れ

### 録画結果を登録する場合

1. 録画実行から番組情報と録画ファイルを受け取る。
2. 録画済み番組、録画ファイル、必要なドロップログを登録する。
3. 録画中に番組情報が変わった場合は録画済み番組へ反映する。
4. 録画終了後は録画中状態、ファイル配置、最終サイズ、履歴を更新する。

### 録画済み番組を削除する場合

1. 対象の存在と保護状態を確認する。
2. 利用者削除では、関係機能が必要なエンコード取消と録画停止を終えた後の削除依頼を受ける。
3. 録画ファイル、サムネイル、ドロップログを削除する。
4. 各登録情報と録画済み番組を削除し、変更を通知する。

## 異常時の動作

-   対象の録画済み番組、録画ファイル、保存先が存在しない場合は対象の操作を失敗として扱う
-   ファイルの移動または登録に失敗した場合は、作成済みファイルの削除を試みる
-   実ファイルの削除に失敗した場合はログへ記録し、続行できる登録情報の削除を試みる
-   クリーンアップ中の一件に失敗しても、処理できる他の対象を続ける

## 他の機能との関係

### 利用する機能

-   サーバー設定管理機能（`server-configuration`）: 録画保存先、一時録画先、ドロップログ保存先、および履歴保存期間を提供
    する。
-   運用ログ記録機能（`server-operational-logging`）: 録画済み情報と実ファイルの操作結果や異常を記録する。
-   データベース保存・検索機能（`server-persistence`）: 録画済み番組、関連情報、および録画履歴を保存・検索する。

### この機能を利用する機能

-   サーバー起動・稼働管理機能（`server-application-runtime`）: 起動時に録画済み情報と実ファイルの整理を依頼する。
-   録画ファイル変換（エンコード）機能（`server-encoding`）: 変換元ファイルを取得し、変換結果の登録や元ファイルの削除を
    依頼する。
-   状態変化通知・外部連携機能（`server-event-and-hook-delivery`）: 録画済み番組、録画ファイル、およびタグの状態変化を通
    知に利用する。
-   バックアップ・復元・旧版移行機能（`server-management-tools`）: 録画済み番組情報をバックアップ、復元、および旧版移行
    の対象として扱う。
-   映像配信・再生連携機能（`server-media-delivery`）: 録画済み番組と録画ファイルを再生に利用する。
-   サーバー内部のプロセス間通信機能（`server-process-messaging`）: 受け付けた録画済み番組の操作を依頼する。
-   予約録画実行機能（`server-recording-execution`）: 録画結果、録画ファイル、ドロップ情報、および録画履歴の登録を依頼す
    る。
-   自動予約ルール機能（`server-reservation-rules`）: 録画履歴を重複判定に利用し、削除したルールとの関連整理を依頼する。
-   Web・API・リアルタイム通知提供機能（`server-service-interface`）: 一覧と詳細を取得し、管理操作やアップロード結果の反
    映を依頼する。
-   録画保存先の容量管理機能（`server-storage-management`）: 容量確保のために録画済み番組と関連情報の削除を依頼する。
-   録画済み番組のサムネイル管理機能（`server-thumbnail-management`）: 生成元の録画ファイルと関連先の録画済み番組を取得
    する。
-   機能間連携機能（`server-workflow-coordination`）: 録画完了後などに録画履歴、録画済み番組、録画ファイル、およびタグの
    後続処理を依頼する。

## この機能に含めないもの

-   録画予約と録画時刻を決めること
-   録画、エンコード、配信を実行すること
-   サムネイル画像を生成すること
-   アップロード受信中の容量や時間を制限すること
-   容量不足を監視して自動削除候補を選ぶこと
