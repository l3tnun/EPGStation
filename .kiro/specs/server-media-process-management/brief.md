# メディア変換プロセス管理機能

## この機能が提供するもの

録画ファイルのエンコードと、ライブ放送・録画ファイルの再生用変換が共有する外部プロセスの実行数を管理する機能である。

設定された上限に空きがあれば変換処理を開始する。空きがない場合、エンコードは再生用変換より高い優先度を持ち、直近に登録さ
れた低優先度の処理を停止できた場合だけ、その枠で開始する。待ち行列は持たず、開始できない要求はその場で失敗する。

## 主な機能

### 共有実行数の制限

-   エンコードと再生用変換へ一つの同時実行上限を適用する
-   実行中の外部プロセスと、その優先度を管理する
-   実行中数が上限未満であれば新しい変換処理を開始する
-   上限が0の場合は変換処理を開始しない
-   変換を行わず映像をそのまま配信する場合は実行枠を使用しない

同時実行上限は機能の起動時に読み込む。稼働中に設定を変更しても、機能を再起動するまでは反映しない。

### 優先度による受付

-   録画ファイルのエンコードを高優先度として扱う
-   ライブ放送と録画ファイルの再生用変換を低優先度として扱う
-   上限到達時に、新しい要求より低い優先度の処理があれば入れ替えを試みる
-   同じか高い優先度の処理しかない場合は、既存処理を停止せず新しい要求を失敗とする
-   待ち行列は持たず、空きが生じても失敗した要求を自動的に再実行しない

停止対象が複数ある場合は、実行中一覧へ直近に登録された、新しい要求より低優先度の処理を選ぶ。

### 低優先度処理との入れ替え

-   選んだ低優先度処理へ停止を要求する
-   停止対象の終了通知を最大3秒待つ
-   3秒以内に終了を確認できた場合だけ、新しい変換処理を開始する
-   3秒以内に終了を確認できない場合は、新しい変換処理を開始せず失敗とする
-   停止操作そのものにも有限の待ち時間を適用する

### 実行枠の解放

-   外部プロセスが正常終了した場合に実行中一覧から取り除く
-   外部プロセスが成立しなかった起動エラー、または終了を確認できる異常終了の場合も実行中一覧から取り除く
-   正常な起動後のエラーだけでは実行枠を解放せず、対象プロセスの終了確認まで一覧へ保持する
-   解放後の空き枠は、後から届いた開始要求が利用できる
-   終了した処理を自動的に再起動しない

エンコード結果、再生状態、利用者への通知は、変換を依頼した機能が管理する。

## 変換処理を開始する流れ

1. エンコードまたは映像配信が、変換内容と優先度を指定して開始を要求する。
2. 実行中数が上限未満であれば、新しい外部プロセスを開始して実行中一覧へ追加する。
3. 上限に達している場合は、新しい要求より低優先度の処理を直近に登録されたものから探す。
4. 対象がなければ開始要求を失敗とする。
5. 対象があれば停止を要求し、終了通知を最大3秒待つ。
6. 終了を確認できた場合だけ新しい外部プロセスを開始し、確認できなければ開始要求を失敗とする。

## 異常時の動作

-   外部プロセスの開始要求が受付前に失敗として返された場合は、その要求を失敗とする
-   入れ替え対象の終了を3秒以内に確認できない場合は置き換え先を開始しない
-   外部プロセスが成立しなかった起動エラー、または終了を確認できる異常終了の場合は実行中一覧から取り除く
-   正常な起動後にエラーだけを確認した場合は、対象プロセスの終了を確認するまで実行中一覧へ保持する
-   失敗した開始要求や終了した処理を自動的に再実行しない
-   サーバー全体の終了時に、この機能だけですべての外部プロセスを停止して回収する動作は提供しない

## 他の機能との関係

### 利用する機能

-   サーバー設定管理機能（`server-configuration`）: エンコードと再生用変換で共有する同時実行上限を提供する。
-   運用ログ記録機能（`server-operational-logging`）: 変換処理の開始、入れ替え、起動失敗、停止失敗、実行中のchildの`error`、およびHLS writerの強制解放を記録する。

### この機能を利用する機能

-   録画ファイル変換（エンコード）機能（`server-encoding`）: 高優先度の変換開始を要求し、待機列、進捗、取消、および出力
    結果を管理する。
-   映像配信・再生連携機能（`server-media-delivery`）: 低優先度の変換開始を要求し、視聴状態と配信終了を管理する。

## この機能に含めないもの

-   エンコード依頼の待機列、進捗、取消、変換結果の登録
-   ライブ視聴と録画再生の受付、視聴状態、配信停止
-   HLSの一時ファイル管理
-   変換形式や画質を選ぶこと
-   失敗した変換処理を自動的に再実行すること
-   サーバー全体の起動順序と終了順序
