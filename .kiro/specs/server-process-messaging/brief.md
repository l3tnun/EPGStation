# サーバー内部のプロセス間通信機能

## この機能が提供するもの

Web UI・API を受け付ける処理と、予約・録画などを管理する処理の間で、依頼、結果、状態変化の知らせを受け渡す機能である。

Web UI から受け付けた状態変更を管理側へ届け、処理結果またはエラーを依頼元へ返す。反対方向には、エンコードの開始依頼
や、Web UI へ最新状態の再取得を促す通知を届ける。

## 主な機能

### Web・API 側から管理側への依頼

-   予約の追加、編集、取消、再計算、スキップ・重複状態の変更を依頼する
-   利用可能な放送波の状態照会を依頼する
-   録画済み番組の手動作成、削除、保護、動画追加、個別動画削除、アップロード結果の登録、不要ファイルの整理を依頼する
-   録画済み番組のタグ作成、変更、関連付け、削除を依頼する
-   自動予約ルールの作成、変更、有効化、無効化、削除を依頼する
-   サムネイルの作成、再作成、削除、不要ファイルの整理を依頼する
-   録画予定の再確認や、エンコード完了結果の反映を依頼する

各依頼の可否と、実際にどの状態を変更するかは依頼先の機能が決定する。

### 依頼と応答の受け渡し

1. Web・API 側が、操作の対象、操作名、必要な引数、数値の識別番号を送る。
2. 管理側が対象と操作名を確認し、担当機能へ処理を依頼する。
3. 担当機能の結果またはエラーを、同じ識別番号を付けて返す。
4. Web・API 側が、同じ識別番号を待つ依頼へ応答を渡す。

複数の依頼を一件ずつ完了させてから次へ進める制御や、重複した依頼の排除は行わない。各依頼の完了順は、処理にかかる時間に
よって変わる場合がある。

### 応答待ちの期限

-   通常の依頼は、送信後 5 秒以内に応答がなければ応答待ちを失敗とする
-   動画アップロード結果の登録は、送信後 10 分以内に応答がなければ応答待ちを失敗とする
-   録画ファイルとドロップログの一括整理には、有限な応答待ち期限を追加する

応答待ちの期限を超えても、依頼先ですでに始まった処理は取り消さない。期限後に届いた応答は、期限超過した依頼の結果として採
用しない。

### 管理側から Web・API 側への通知

-   予約、録画、録画済み番組、タグ、ルール、サムネイルなどの状態変化後に、Web UI へ最新状態の再取得を促す
-   録画完了後などに必要となるエンコードを、Web・API 側で受け付けるよう依頼する

通知は結果を待たず、通知先が利用できない間の保存や再送を行わない。

## 異常時の動作

-   依頼先の処理がエラーになった場合は、そのエラーを依頼元へ返す
-   指定された対象または操作が存在しない場合は、操作を実行せずエラーを返す
-   必要な引数がない場合は、操作を実行せずエラーを返す
-   応答待ちの期限超過は、依頼先の処理完了または取消を意味しない
-   Web・API 側が再起動しても再起動前の依頼待ちは復元せず、遅れて完了した応答を再起動後の別依頼へ渡さない
-   通知の送信先が利用できない場合、通知を保存または再送しない

## 他の機能との関係

### 利用する機能

-   運用ログ記録機能（`server-operational-logging`）: 送信不能や応答待ちの異常を記録する。
-   録画ファイル変換（エンコード）機能（`server-encoding`）: エンコード依頼を受け付け、完了結果を返す。
-   録画済み番組管理機能（`server-recorded-content`）: 依頼された録画済み番組操作の意味と可否を決定する。
-   予約録画実行機能（`server-recording-execution`）: 依頼された録画操作の意味と可否を決定する。
-   録画予約管理機能（`server-reservation-management`）: 依頼された予約操作の意味と可否を決定する。
-   自動予約ルール機能（`server-reservation-rules`）: 依頼されたルール操作の意味と可否を決定する。
-   録画済み番組のサムネイル管理機能（`server-thumbnail-management`）: 依頼されたサムネイル操作の意味と可否を決定する。

### この機能を利用する機能

-   サーバー起動・稼働管理機能（`server-application-runtime`）: 通信相手を起動して登録する。
-   状態変化通知・外部連携機能（`server-event-and-hook-delivery`）: 別々に動くサーバー機能へ状態変化を渡す。
-   Web・API・リアルタイム通知提供機能（`server-service-interface`）: 外部から受け付けた操作を管理側へ送り、結果をHTTP応
    答へ変換する。

## この機能に含めないもの

-   予約、録画、録画済み番組、ルール、サムネイル、エンコードの業務判断
-   Web ブラウザーへリアルタイム通知を配信する方法
-   外部コマンドの実行と結果管理
-   Web・API 側の処理を起動、監視、再起動すること
-   通信相手以外の外部システムとの通信
