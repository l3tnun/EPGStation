# バックアップ・復元・旧版移行機能

## この機能が提供するもの

EPGStation の管理者が、ルール、予約、録画済み番組などの管理情報を一つのファイルへバックアップし、そのファイルから復元で
きるようにする機能である。また、EPGStation v1 のバックアップから対応する管理情報を移行する。

この機能が扱うのはデータベースに保存された管理情報である。録画映像、サムネイル画像、ドロップログなどの実ファイル自体は
バックアップ、復元、移動しない。

## 主な機能

### 管理情報のバックアップ

次の情報をデータベースから順番に読み出し、一つの JSON ファイルへ出力する。

-   自動予約ルール
-   録画予約
-   録画済み番組
-   録画ファイルの管理情報
-   サムネイルの管理情報
-   ドロップログの管理情報
-   録画履歴
-   録画済み番組のタグ

バックアップは版番号を持たない JSON 形式とする。

録画済み番組とタグ本体は対象に含むが、どのタグがどの録画済み番組に付いているかという関連付けは含めない。

### 管理情報の復元

1. 指定されたファイルを読み込み、JSON として解釈する。
2. バックアップに含まれる対象種類の管理情報を復元する。
3. 処理の進行と失敗を管理者向け出力へ記録する。

復元対象は、この機能が出力する版番号を持たないバックアップ形式である。設定ファイルや実ファイルは復元しない。

### EPGStation v1 からの移行

-   移行元を v1 の最終データベース構造へ更新して作成したバックアップを移行対象とする
-   v1 のバックアップファイルを読み込む
-   v1 の自動予約ルールを本仕様のルールへ変換する
-   旧ルールと移行後のルールを対応付け、録画済み番組との関連を引き継ぐ
-   録画済み番組、サムネイル、元の録画ファイル、エンコード済みファイルの管理情報を移行する
-   録画履歴を移行する

旧版移行も管理情報だけを登録し、実ファイルを移動しない。

v1 の予約とドロップ情報は移行しない。録画済み番組は録画中ではない未保護の状態として登録し、v1 の音声サンプリング周波数、
未変換の詳細情報、ログ位置、エラー数、ドロップ数、スクランブル数、一時録画状態は引き継がない。

### 管理コマンド

-   `backup` では操作種別と出力先を指定する
-   `restore` では操作種別と入力元を指定する
-   `v1migrate` では v1 バックアップの入力元を指定する
-   必須の指定が不足または不正な場合は、データベース処理を開始せず失敗として終了する
-   管理者が通常稼働中の EPGStation を停止してから実行する
-   データベースへ接続できることを確認してから管理情報を処理する
-   データベースへ接続できない場合は1秒待って再確認し、一回ごとの確認にも待機期間全体にもEPGStation独自の時間制限を追加
    しない

Windows サービスの登録と解除を呼び出す既存の `install-win-service` と `uninstall-win-service` は残す。ただし、Windows上
の動作を対応対象または検証済みとは表明しない。

## 管理者から見た動作

-   入出力先は管理者が明示的に指定する
-   処理対象の種類が進むごとに進行状況を確認できる
-   管理情報のバックアップだけでは録画映像や画像を復旧できない
-   バックアップ、復元、旧版移行は、稼働中の EPGStation を自動停止しないため、管理者が事前に停止する
-   正常終了時はデータベース接続を閉じ、成功を表す終了状態を返す
-   入力または処理に失敗した場合は、失敗を表す終了状態を返す

## 他の機能との関係

### 利用する機能

-   サーバー設定管理機能（`server-configuration`）: データベース接続、録画保存先、エンコード方法などの設定を提供する。
-   運用ログ記録機能（`server-operational-logging`）: バックアップ、復元、および移行の進行と失敗を記録する。
-   データベース保存・検索機能（`server-persistence`）: 管理情報の読み出し、置き換え、および追加を提供する。
-   録画予約管理機能（`server-reservation-management`）: 対象となる予約情報の意味を定める。
-   自動予約ルール機能（`server-reservation-rules`）: 対象となるルール情報の意味を定める。
-   録画済み番組管理機能（`server-recorded-content`）: 対象となる録画済み番組情報の意味を定める。
-   録画済み番組のサムネイル管理機能（`server-thumbnail-management`）: 対象となるサムネイル情報の意味を定める。

### この機能を利用する機能

-   なし

## この機能に含めないもの

-   録画映像、サムネイル画像、ドロップログなどの実ファイルの保全
-   録画済み番組とタグの関連付けのバックアップと復元
-   サーバー設定ファイルのバックアップと復元
-   データベース自体のバックアップ、遠隔保存、暗号化
-   定期実行とバックアップの自動保持
-   通常運用の自動停止
-   復元後の予約再計算やサムネイル再生成
